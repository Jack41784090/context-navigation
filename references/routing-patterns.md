# Routing patterns

Read while choosing disclosure boundaries. Examples below are synthetic. Replace
names and triggers with the project's actual contracts.

## Trace the chain

Build a small map rather than a bulk document dump:

`entrypoint -> matching skill -> applicable contract -> relevant reference`

For each edge record whether reading is mandatory, conditional or merely
navigational. Trace explicit prerequisites transitively until no new relevant
obligation appears. A cyclic pointer can identify shared ownership, but should not
make an agent repeatedly reload the same unchanged document.

Include entrypoints automatically loaded by the host and inherited instructions
outside the folder. Resolve physical files behind aliases. Count one source once
for a unique-document model, but count repeated loads if measuring actual reads.
State which model you use.

## Preserve obligations by branch

| Obligation | Trigger | Suitable home | Check |
| --- | --- | --- | --- |
| Author controls acceptance | Before evaluating authority or changing accepted material | Short root invariant plus acceptance contract | Proposals cannot become accepted through task completion |
| Recording | At the original session or decision boundary | Root trigger plus recording workflow | Fresh and resumed work both reach it |
| Native mutation safety | Before discovery, preview or execution as required | Tool-boundary pointer and operation contract | Read-only discovery cannot bypass the restriction |
| Explicit permission | Before using an allowed exception or parallel workflow | Same boundary as its restrictions | Preserve isolation, coordination and other conditions without banning the allowed case |
| Runtime ownership | Before behavior changes, design or review of affected boundaries | Owner map and relevant transaction contract | Cross-owner proposal loads both sides |
| Plain operating documents | Before creating, placing or changing document properties | Documentation conventions | No accidental native adoption or creative acceptance |
| Imported helper | Before following a script example or executing a helper | Compatibility gate plus helper reference | No unauthorized install, mutation or data upload |
| Historical migration | When auditing or explicitly migrating | Evidence and migration contract | Old commands are not executed at startup |

The exact placement is contextual. Do not move a critical rule behind a trigger
that requires already knowing that rule to recognize it.

## Before and after

Before:

> Read schema.md, themes.md, craft.md, operations.md and every linked reference
> before starting any task.

After, only if consistent with the project's actual policy:

| Task boundary | Read before crossing it |
| --- | --- |
| Session start while trial mode is active | trial-policy.md |
| Create or interpret managed records | schema.md and the affected lifecycle contract |
| Interpret or revise creative material | themes.md and relevant accepted source notes |
| Brainstorm or draft scenes | craft.md plus the creative-material row |
| Change behavior across runtime owners | ownership.md and each affected transaction/persistence boundary |
| Plain operating-document maintenance | documentation-conventions.md |
| Execute a helper | tool-policy.md, compatibility.md and the helper's instructions |
| Audit provenance | historical evidence for the specific claim |

Combine applicable rows. Preserve the standing invariants before this table.
An operations index becomes navigation, not an instruction to read all audits.

## Common traps

- **Safety orphan:** a deleted startup paragraph was the only reachable CLI ban.
  Restore its meaning in a visible boundary, not merely in a dated audit.
- **Hidden eager load:** an imported compatibility note still demands all the
  foundations after the root was shortened. Follow the whole applicable chain.
- **Mutation-only trigger:** planning, reviews or interpretation need contracts
  too. Tie gates to the decision boundary, not just file writes.
- **Authority drift:** a proposed schema or cited source is mistaken for accepted
  policy. Preserve the distinction between evidence, proposal and authorization.
- **Recording opt-in:** changing "record at meaningful boundaries" to "export on
  request" silently weakens behavior. Preserve automatic triggers.
- **Read-only bypass:** discovery can launch applications, expose private data or
  require grants. Keep the original tool restrictions before discovery.
- **Extraction drift:** moved prose refers to "above" or uses a different relative
  path base. Normalize deliberately and compare every other body byte.
- **Alias duplication:** replacing a symlink with a second file creates competing
  sources of truth. Preserve topology unless change is explicitly authorized.
- **Oversized router:** copying every caveat into a table recreates the manual.
  Keep concise invariants inline and route cohesive details with strong triggers.
- **Dirty-tree sweep:** whole-file staging captures another author's changes.
  Stage owned hunks and inspect the index, including its final entrypoint content.
